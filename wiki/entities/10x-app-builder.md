# 10X — App Builder iOS por Descrição

> Plataforma que converte uma descrição em linguagem natural em um app iOS nativo (SwiftUI) pronto para submissão na App Store — sem Xcode, sem semanas de desenvolvimento.

## O que é

10X é uma ferramenta de vibecoding específica para mobile nativo que implementa o paradigma "descreve → gera → publica":

| Input | Output |
|-------|--------|
| Descrição em linguagem natural da ideia | App iOS nativo em SwiftUI |
| — | Screenshots prontos para App Store |
| — | App Store ready (metadata incluída) |

## Diferenciais

- **Sem Xcode**: elimina a barreira de entrada mais alta do desenvolvimento iOS
- **Nativo Swift**: output em SwiftUI, não wrapper web (React Native, Flutter)
- **End-to-end**: da ideia ao app publicável, incluindo assets da App Store
- **Sem semanas de espera**: ciclo comprimido, alinhado ao paradigma vibecoding

## Relevância para o wiki

Primeira ferramenta do wiki específica para iOS nativo via IA. Enquanto outras fontes cobrem geração de web apps (Claude Code + Lovable + Quepo), o 10X expande o conceito de vibecoding para o mobile nativo — o paradigma "descreve e aparece" chega ao SwiftUI.

Contraste com o stack web: [[lovable]] gera landing pages/web apps → [[10x-app-builder]] gera apps iOS nativos.

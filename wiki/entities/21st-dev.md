# 21st Dev — Marketplace de Componentes com Camada de IA

> Marketplace de componentes de UI com geração por IA: o usuário descreve o componente e ele é gerado instantaneamente, sem precisar navegar por um catálogo estático.

## O que é

21st Dev combina marketplace (catálogo de componentes prontos) com geração generativa (IA cria o componente a partir de descrição):

| Modo | Como funciona |
|------|---------------|
| Marketplace | Navegar e usar componentes existentes de outros devs |
| Geração por IA | Descrever o componente → IA gera o código |

## Posição no ecossistema vibecoding

Complementa [[shadcn-ui]] (biblioteca base estática) ao adicionar geração on-demand. O fluxo típico:
1. ShadCN: componentes base do projeto (Button, Card, Input etc.)
2. 21st Dev: componentes específicos gerados por descrição ("crie um timeline animado com ícones")

## Relevância para o wiki

Representa o padrão "marketplace + IA generativa" que está emergindo em várias camadas do desenvolvimento:
- Smithery ([[smithery]]): marketplace de Skills/MCPs para Claude
- 21st Dev: marketplace de componentes de UI com IA

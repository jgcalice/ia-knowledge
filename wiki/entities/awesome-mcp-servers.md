# awesome-mcp-servers

> **Categoria:** Ferramenta | **Tipo:** Catálogo curado de servidores MCP (GitHub, 92k ⭐)

## O que é

Repositório `punkpeye/awesome-mcp-servers` — catálogo com milhares de servidores MCP (Model Context Protocol) prontos para conectar agentes de IA a navegadores, bancos de dados e praticamente qualquer sistema externo.

## Posição no ecossistema

Primeiro *catálogo* de servidores MCP documentado no wiki — complementa [[smithery]] (marketplace de 128k+ Claude Skills/MCPs) como referência de descoberta, mas em formato de lista curada aberta em vez de marketplace comercial. Relevante para qualquer pipeline de [[agentes-ia]] que precise conectar Claude a sistemas externos sem construir a integração do zero.

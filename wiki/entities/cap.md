# Cap

> **Categoria:** Ferramenta open-source de gravação de tela · **Repositório:** `github.com/CapSoftware/Cap`

## O que é

Alternativa open-source ao Loom: grava, edita e compartilha gravações de tela em Mac ou Windows. Resolve o problema de custo recorrente por assento do Loom. Auto-hospedagem via um único comando (`docker compose up -d`), mantendo a propriedade dos dados ("Your recordings stay yours").

## Modos

- **Instant Mode** — compartilha o link assim que a gravação para
- **Studio Mode** — edição, legendas, exportação em 4K

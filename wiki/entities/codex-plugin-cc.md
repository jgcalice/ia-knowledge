# codex-plugin-cc

> **Categoria:** Plugin oficial da OpenAI · **Repositório:** `github.com/openai/codex-plugin-cc`

## O que é

Plugin oficial lançado pela **OpenAI** que executa o Codex dentro do [[claude-code]] — primeiro caso documentado no wiki de uma lab de IA construindo integração oficial dentro do produto de uma concorrente direta. Funciona na camada gratuita do ChatGPT.

## Comandos

| Comando | Função |
|---------|--------|
| `/codex:review` | Segunda opinião sobre o diff atual |
| `/codex:adversarial-review` | Ataca intencionalmente as suposições do código |
| `/codex:rescue` | Assume uma sessão travada |

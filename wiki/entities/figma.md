# Figma (MCP)

> **Categoria:** Plataforma de design · **Papel no wiki:** MCP que conecta o Claude ao Figma para montagem direta de sites

## O que é

Figma é a plataforma de design de interfaces mais usada do mercado. Via MCP (Model Context Protocol), o Claude ganha acesso direto ao Figma para montar layouts de site sem que o operador precise desenhar manualmente cada tela.

## Papel no stack documentado

Um dos 5 componentes do setup de [[vinicius-delmonego]] para sites profissionais com Claude — ao lado das skills Milkovalski Design, Impeccable Design, Taste Skill e do MCP [[playwright]]. O MCP Figma é a etapa de **montagem**: depois que a Taste Skill busca inspiração e as skills de design definem layout/tipografia/espaçamento, o Figma é onde o site é efetivamente construído.

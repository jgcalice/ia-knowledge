# Forrest Chang

Developer autor de um plugin Claude Code com ~42.300 stars no GitHub (39k no momento da divulgação por [[max-kelley]]). O plugin endereça os 3 problemas crônicos do Claude Code default citados pelo "godfather of Vibe coding" (provável [[andrej-karpathy]]):

1. **Suposições silenciosas** — o Claude escolhe sozinho o que o usuário "queria"
2. **Sobre-engenharia** — uma pequena mudança vira mil linhas
3. **Regressões em cascata** — corrigir A quebra B, C, D

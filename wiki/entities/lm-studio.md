# LM Studio

> **Categoria:** Ferramenta | **Tipo:** Runner GUI para LLMs locais

## O que é

LM Studio é uma aplicação desktop com interface gráfica (GUI) para baixar e executar modelos de linguagem abertos localmente. Funciona como alternativa ao [[ollama]] para quem prefere evitar o terminal.

## Diferencial vs Ollama

| | Ollama | LM Studio |
|---|--------|-----------|
| Interface | CLI | GUI completa com model browser |
| Chat integrado | Não nativo (usar Open WebUI) | Sim, embutido na aplicação |
| Perfil | Power users, devs | Iniciantes, usuários não-técnicos |
| Instalação | Um comando (curl) | Installer gráfico |

"Se o terminal te assusta, comece aqui." — @hasantoxr

Os modelos são os mesmos e a qualidade é idêntica — a diferença é apenas a porta de entrada para o ecossistema de [[ia-local]].

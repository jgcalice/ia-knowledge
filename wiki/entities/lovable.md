# Lovable

> **Categoria:** Ferramenta / No-code builder | **Aparece em:** 1 fonte

## O que é

Lovable é uma ferramenta de criação de landing pages e aplicações web via prompts, capaz de gerar uma página funcional com URL ao vivo em aproximadamente 5 minutos. Permite especificar audiência, tom, paleta de cores, estrutura de seções e comportamento visual diretamente no prompt.

## Papel no wiki

[[derek-gray]] usa o Lovable como terceiro elo do stack de monetização local:

```
Google Maps → Claude (diagnóstico + brief) → Lovable (landing page) → Outreach
```

O mockup gerado pela Lovable é o argumento de venda: o prospect recebe um link funcional personalizado para seu negócio antes mesmo de qualquer conversa comercial.

## Prompt documentado

Estrutura do prompt de Derek Gray:

```
Build a landing page for [business name], a [specific business type] in [city].

Audience: [describe specifically]
Brand feel: [3 specific adjectives]
Hero focus: [angle from Claude's brief]

Sections:
1. Hero with primary CTA
2. Three core services
3. About with credibility positioning
4. Social proof / testimonials placeholder
5. Final CTA section

Design: [specific color palette, not "modern"], generous whitespace,
mobile-first, subtle scroll animations, no flashy effects.
Tone: [specific to industry]

Avoid: AI-looking gradients, generic stock photos,
"Welcome to" headlines, "Your trusted partner" copy.
```

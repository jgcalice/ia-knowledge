# Motion Primitives — Animações Copy-Paste para Vibecoding

> Biblioteca de código de animação pronto para copiar e colar, eliminando a necessidade de escrever lógica de animação do zero.

## O que é

Motion Primitives fornece snippets de animação já implementados que podem ser inseridos diretamente no projeto — o desenvolvedor não precisa entender ou escrever a mecânica da animação, apenas aplicar o código pronto.

Primeira ferramenta do wiki dedicada especificamente a animação como categoria própria dentro do stack de vibecoding — complementa bibliotecas de componentes estáticos como [[shadcn-ui]] e [[watermelon-ui]].

# n8n

> **Categoria:** Ferramenta | **Tipo:** Plataforma de automação de workflows open-source

## O que é

n8n é uma plataforma de automação de fluxo de trabalho (workflow automation) open-source, self-hostável, frequentemente descrita como "Zapier open-source". Oferece:

- **400+ integrações** nativas com serviços externos
- **Capacidades nativas de IA** para construção de agentes e pipelines de LLM
- **Licença fair code** — gratuito para self-hosting; pago para cloud
- Interface visual de drag-and-drop + possibilidade de código customizado

## Modelo de negócio documentado

[[harish-bhatt]] menciona n8n como base para serviços de automação cobrados a **$500–$2.000 por configuração** — o operador monta um workflow personalizado para o cliente, hospeda (ou entrega para o cliente hospedar) e cobra pela entrega. A empresa n8n captou $14M, validando que o modelo de agência por trás funciona.

## Relevância no wiki

Primeira aparição do n8n no wiki. É alternativa direta ao Zapier e ao Make (Integromat) — duas das ferramentas mais citadas no ecossistema de automação.

# NocoDB

> **Categoria:** Ferramenta | **Tipo:** Smart spreadsheet database open-source | **Substitui:** Airtable

## O que é

Repositório GitHub gratuito que replica as funcionalidades do Airtable: grids, forms, pipelines, Kanban e API. Diferencial citado: pode ser instalado sobre um banco de dados já existente, em vez de exigir migração completa de dados.

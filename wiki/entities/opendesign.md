# OpenDesign

> **Categoria:** Ferramenta | **Tipo:** Modelo de design open-source

## O que é

Repositório GitHub gratuito apresentado como substituto de modelos de design por IA. Segundo a transcrição do post, seria executável via modelos/roteadores de terceiros e teria desempenho superior a alternativas comerciais.

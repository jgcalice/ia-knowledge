# public-apis

> **Categoria:** Ferramenta | **Tipo:** Catálogo de APIs gratuitas (GitHub, 456k ⭐)

## O que é

Repositório `public-apis/public-apis` — catálogo com mais de 1.400 APIs gratuitas organizadas em 50 categorias (clima, finanças, imagens, jogos, entre outras), todas documentadas com endpoint e método de autenticação.

## Posição no ecossistema

Junto com [[free-for-dev]], preenche uma lacuna do wiki: até aqui os repos open-source documentados substituíam ferramentas específicas (CRM, TTS, scraping); public-apis é um catálogo de *acesso a centenas de recursos gratuitos de uma vez*, reduzindo custo de integração para qualquer arquétipo de negócio ou agente documentado em [[agentes-ia]].

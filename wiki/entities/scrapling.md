# Scrapling

> **Categoria:** Ferramenta | **Tipo:** Web scraping indetectável (GitHub, 73.6k ⭐)

## O que é

Repositório `D4Vinci/Scrapling` — biblioteca de raspagem web com bypass de Cloudflare embutido e comportamento indetectável por sistemas anti-bot. Apresentado na fonte como substituto de APIs de scraping pagas (~$300/mês).

## Posição no ecossistema

Mais uma alternativa open-source a ferramentas de scraping pagas, no mesmo domínio de [[crawl4ai]] (alternativa ao [[apify]]) e do "Navegador Stealth" documentado por [[paras-madan]]. Relevante para os pipelines de [[geração-de-leads-com-ia]] que dependem de extração de dados web ([[hudson-brendon]], [[lucas-garcia-pit]], [[arshman-khalid]]).

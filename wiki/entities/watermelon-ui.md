# Watermelon UI — Biblioteca Open Source para Landing Pages

> Biblioteca de componentes open source voltada para montagem rápida de landing pages "production ready".

## O que é

Watermelon UI oferece componentes de UI prontos, focados especificamente em páginas de destino (landing pages), permitindo montar sites mais rápido sem construir cada elemento visual do zero.

## Posicionamento no wiki

Junta-se a [[shadcn-ui]] como biblioteca de componentes de base para vibecoding, mas com foco mais estreito: enquanto ShadCN é generalista (qualquer tipo de interface), Watermelon UI é especializado em landing pages.

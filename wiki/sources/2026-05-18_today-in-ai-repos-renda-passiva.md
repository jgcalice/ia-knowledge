# 10 Repos GitHub para Receita Passiva: Fork, White-label e Venda

> **Fonte:** [[2026-05-18_today_in_ai_DYd32iAEsd1]] | **Autor:** @TODAY IN AI (aitickerdaily) | **Data:** 2026-05-18 | **Formato:** carousel | **[↗ Ver post](https://www.instagram.com/p/DYd32iAEsd1/?img_index=7)**

## TL;DR

10 repositórios open-source do GitHub com modelos de negócio concretos para white-label e SaaS recorrente — prova social das próprias empresas originais (Cal.com $5M ARR, Supabase $116M captados, n8n $14M captados).

## Contexto

Carousel de 8 slides criado por aitickerdaily (editorial de IA do curatedai.net), publicado em @TODAY IN AI. Enquadramento: "repos que imprimem dinheiro enquanto você dorme" — fork → white-label → vender como serviço mensal. Reforça o mesmo ângulo do primeiro post de [[harish-bhatt]] (2026-05-16), com nichos verticais mais específicos para cada produto.

## O que foi ensinado

| # | Repo | Substitui | Modelo de monetização documentado |
|---|------|-----------|----------------------------------|
| 1 | **Cal.com** | Calendly | $200/mês por cliente em nichos profissionais (dentistas, advogados) |
| 2 | **Plausible Analytics** | Google Analytics | $50/mês por cliente para agências — self-host + revenda |
| 3 | **Ghost** | Substack | 1.000 leitores × $5/mês = $60K/ano, 100% margem sem plataforma |
| 4 | **[[n8n]]** | Zapier | $500–$2.000 por setup de automação; $14M captados |
| 5 | **Supabase** | Firebase | SaaS de fim de semana a $29–$99/mês; $116M captados |
| 6 | **Medusa** | Shopify | Lojas sem rev share — operador fica com parte das vendas |
| 7 | **AppFlowy** | Notion | Self-hosted para empresas que não aceitam cloud; privacidade como diferencial |
| 8 | **Coolify** | Vercel / Heroku | $20/mês por gerenciamento de deploys para devs |
| 9 | **Listmonk** | Mailchimp | Email em custo de AWS → revenda com markup na camada gerenciada |
| 10 | **Penpot** | Figma | Workflows de design self-hosted para agências com restrições de cloud |

**Decisão central documentada**: a diferença não é feature vs feature — é se você faz o fork e sobe a landing page este fim de semana. Os fundadores já validaram a distribuição; o operador escolhe a vertical.

## Insights para o wiki

- **2ª confirmação independente do ângulo white-label SaaS**: fonte totalmente diferente ([[harish-bhatt]] era @codingknowledge; esta é aitickerdaily/curatedai.net) endossa os mesmos repos com o mesmo enquadramento — padrão consolidado
- **Nichos verticais explicitados**: Cal.com para dentistas/advogados, Plausible para agências — mais acionável do que a versão genérica de Harish Bhatt
- **Penpot como novidade relativa**: apareceu no 2º post de Harish Bhatt (ângulo custo zero / "repos ilegais") mas não no 1º (white-label); aqui entra na perspectiva de monetização para agências com restrições de cloud
- **Listmonk**: confirmação como ferramenta de email gerenciado — "envie a custo AWS e revenda com markup"
- **Padrão de prova social**: os ARRs dos fundadores (Cal.com $5M, Plausible 7 dígitos, n8n $14M, Supabase $116M, AppFlowy $30M) funcionam como argumento de viabilidade do modelo — se eles chegaram lá, o nicho vertical menor tem margem suficiente

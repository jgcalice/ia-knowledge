7 repositórios GitHub open-source que substituem coletivamente mais de $6.500/mês em ferramentas SaaS pagas — para email, geração de imagem/vídeo, interface LLM unificada, finanças, edição de vídeo, análise de anúncios e navegação web para agentes de IA.

## Insights para o wiki

- **6ª confirmação independente** do ecossistema de repos GitHub como substitutos de SaaS pago — padrão agora consolidado com seis fontes distintas: [[paras-madan]], [[bestapps-ai]], [[growai]], [[harish-bhatt]], [[today-in-ai]], [[cooper-simson]]
- **LibreChat é novidade**: interface única para todos os LLMs (Claude, ChatGPT, Gemini, e outros) em um só lugar, sem copiar e colar entre plataformas — não documentada antes no wiki

# CRM Open Source: Clone da Salesforce com 51k Stars no GitHub

> **Fonte:** [[2026-06-22_pedro_mallet_DZ5qJ2ju1h5]] | **Autor:** @Pedro Mallet | **Data:** 2026-06-22 | **Formato:** Reel (50s) | **[↗ Ver post](https://www.instagram.com/reel/DZ5qJ2ju1h5/)**

## TL;DR

Um CRM open source com funcionalidades equivalentes às da Salesforce viralizou no GitHub com 51.000 estrelas — pode ser instalado na própria infraestrutura e personalizado com Claude Code.

## Contexto

@Pedro Mallet apresenta um repositório GitHub que replica as funcionalidades da Salesforce em formato open source, permitindo que qualquer empresa tenha seu próprio CRM dentro de sua infraestrutura sem pagar licença. O post viralizou no nicho de IA aplicada a negócios e o autor oferece um guia de instalação com boas práticas via engajamento nos comentários.

## O que foi ensinado

- Existe um CRM open source que replica as funcionalidades da Salesforce e pode ser hospedado na própria infraestrutura
- O repositório atingiu 51.000 estrelas no GitHub — confirmação de tração de comunidade expressiva
- É possível personalizar e customizar o sistema com Claude Code (referido no original como "Cloud Code"), adaptando-o às necessidades específicas da empresa
- O autor preparou guia de instalação com boas práticas — acesso via comentário "CRM" no post
- A proposta de valor central: funcionalidades de nível Salesforce sem os custos de licenciamento

## Insights para o wiki

- **8ª confirmação independente do padrão "repos open-source como substitutos de SaaS pago"**: desta vez aplicado a CRM (Salesforce), categoria historicamente cara e de difícil substituição. Confirma que o padrão se estende para além de ferramentas de produtividade (Cal.com, Ghost, n8n) para sistemas de gestão empresarial críticos
- **Salesforce como benchmark de custo**: licenças Salesforce custam tipicamente $25–$300/usuário/mês — o CRM open source self-hosted elimina esse custo inteiramente
- **Personalização via Claude Code como diferencial**: pela primeira vez no wiki, Claude Code é citado como ferramenta de customização de um sistema CRM auto-hospedado — camada de adaptação sem desenvolvimento tradicional
- **Formato engajamento → guia**: padrão "comenta X para receber" sugere que o valor agregado está no setup/instalação, não apenas no repositório em si — alinhado com a tese de [[stics-ai]] ("a oportunidade não é o repo, é saber como usá-lo")

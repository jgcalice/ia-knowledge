# 10 Sites para Vibe Coders: Stack Essencial iOS em Minutos

> **Fonte:** [[2026-06-28_joaquin_fernandez_DaIdKPIysLn]] | **Autor:** @Joaquin Fernandez | **Data:** 2026-06-28 | **Formato:** reel (38s) | **[↗ Ver post](https://www.instagram.com/reel/DaIdKPIysLn/)**

## TL;DR

Cinco ferramentas essenciais que formam a stack de qualquer vibe coder focado em iOS: componentes (ShadCN), app nativo sem Xcode (10X), marketplace de componentes com IA (21st Dev), animações CSS visuais (Animista) e ícones unificados em seis pesos (Phosphor Icons).

## Contexto

Reel de 38 segundos com o formato "10 websites every X should know" — mas o autor nomeia apenas 5. O recorte é explicitamente para "vibe coders", sinalizando que o stack não é para devs tradicionais, mas para quem constrói rápido com LLMs. Hashtags do post: `#10x #vibecoding`.

## O que foi ensinado

**1. ShadCN UI** — _"the base layer almost every vibe coder is building on right now"_
- Biblioteca de componentes de UI bonitos e prontos para uso
- Integra diretamente no projeto (não é instalado como pacote externo — o código fica no repo)
- Base sobre a qual os outros componentes e customizações são construídos

**2. [[10x-app-builder]] (10X)** — _"turns your app idea into a live iOS app"_
- Input: descrição em linguagem natural
- Output: app iOS nativo em SwiftUI, pronto para a App Store (com screenshots)
- Sem necessidade de Xcode, sem semanas de espera
- Caso de uso direto do paradigma vibecoding aplicado ao mobile

**3. [[21st-dev]] (21st Dev)** — _"component marketplace with an AI layer on top"_
- Marketplace de componentes de UI + camada de IA que gera o componente a partir de descrição
- Descreve o que quer → componente gerado instantaneamente
- Complementa ShadCN ao adicionar geração sob demanda

**4. Animista** — _"build CSS animations visually"_
- Interface visual para criar animações CSS: escolhe efeito, ajusta duração e easing, preview em tempo real
- Output: código CSS copiável
- Elimina a necessidade de escrever código de animação do zero

**5. Phosphor Icons** — _"one icon family in six different weights"_
- Um único set de ícones em 6 pesos visuais (thin, light, regular, bold, fill, duotone)
- Cobre todos os estilos visuais de um app
- Workflow: busca → escolhe peso → copia o componente

## Insights para o wiki

- **Vibecoding tem uma stack emergente**: ShadCN + 10X + 21st Dev + Animista + Phosphor formam uma toolchain reconhecível, não ferramentas isoladas. A menção recorrente de ShadCN como "base layer" sugere que é um padrão de facto.
- **10X é a primeira ferramenta do wiki específica para iOS nativo via IA**: nenhuma fonte anterior cobrira geração de app SwiftUI pronto para App Store por descrição. Expande o conceito de vibecoding além de web apps.
- **21st Dev adiciona geração de componentes on-demand**: diferente de bibliotecas estáticas (ShadCN), é um marketplace generativo — a IA gera o componente a partir da descrição, não apenas lista um catálogo.
- **Geração de headshots com IA** ([[2026-06-02_artificial-intelligence-ai-headshots]]) e agora geração de apps iOS (10X) seguem o mesmo padrão de comoditização: tarefas que exigiam especialistas agora têm output descritivo → produto final.

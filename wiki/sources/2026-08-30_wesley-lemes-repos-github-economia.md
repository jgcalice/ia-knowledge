# 10 Repositórios do GitHub que Substituem Ferramentas Pagas

> **Fonte:** [[2026-08-30_wesley_lemes_expert_em_ias_DcrRliGGIwB]] | **Autor:** @Wesley Lemes / Expert em IAs | **Data:** 2026-08-30 | **Formato:** carousel (10 de 12 slides processados) | **[↗ Ver post](https://www.instagram.com/p/DcrRliGGIwB/?img_index=11&stkn=czV6Z2VsOTF0Y25m)**

## TL;DR

Curadoria de 9 repositórios GitHub open-source (mais de 1,8M estrelas combinadas) apresentados como substitutos gratuitos de ferramentas e APIs pagas — mais uma confirmação do padrão "repos open-source substituem SaaS" já consolidado no wiki.

## Contexto

@Wesley Lemes usa o gancho "paguei por ferramenta que já existia de graça no GitHub" com CTA de comentário ("GITHUB") para captura de lead via DM — mesmo padrão editorial e mesmo modelo de geração de leads já documentado em [[growai]], [[paras-madan]] e [[ibra-ai]]. Carousel processado parcialmente (10 de 12 slides; `MAX_SLIDES_TO_PROCESS` no `.env` do pipeline de ingestão limitou a captura).

## O que foi ensinado

- **awesome** (`sindresorhus/awesome`) — "a lista de todas as outras listas"; índice curado de recursos que compila outras listas de referência do GitHub
- **public-apis** (`public-apis/public-apis`, 456k ⭐) — mais de 1.400 APIs gratuitas em 50 categorias (clima, finanças, imagens, jogos), todas documentadas
- **scrapling** (`D4Vinci/Scrapling`, 73.6k ⭐) — raspagem web indetectável com bypass de Cloudflare embutido; alternativa a APIs de scraping pagas (~$300/mês)
- **free-for-dev** (`ripienaar/free-for-dev`, 132k ⭐) — centenas de serviços com tier gratuito permanente, sem trial nem cartão de crédito
- **ollama** (`ollama/ollama`, 178k ⭐) — roda Llama, Mistral e DeepSeek localmente com um comando, sem conta de API nem limite de requisição
- **langflow** (`langflow-ai/langflow`, 153k ⭐) — construtor visual para agentes de IA e pipelines de RAG; publicável como API ou servidor MCP
- **awesome-mcp-servers** (`punkpeye/awesome-mcp-servers`, 92k ⭐) — milhares de servidores MCP para plugar agentes em navegador, banco de dados e outros sistemas
- **open-design** (`nexu-io/open-design`, 85k ⭐) — alternativa open-source a modelos de design por IA; "agente de código vira o motor de design"
- **awesome-llm-apps** (`ShubhamSaboo/awesome-llm-apps`, 132k ⭐) — mais de 100 agentes de IA e apps de RAG prontos, com código completo

## Insights para o wiki

**12ª confirmação do padrão "repos open-source substituem SaaS pago"** — mesma estrutura editorial de [[paras-madan]], [[bestapps-ai]], [[growai]], [[harish-bhatt]] (×2), [[today-in-ai]], [[cooper-simson]], [[stics-ai]], [[pedro-mallet]], [[marc-kaz]], [[ibra-ai]] e [[neeraj-chemburkar]]. Três repositórios já documentados no wiki reaparecem aqui, cada um reforçando um domínio existente:

- [[ollama]] (3ª fonte independente) — confirma execução local de LLMs como categoria madura de "IA local"
- [[opendesign]] (2ª fonte) — confirma design generativo open-source, mas aqui com enquadramento mais confiável (sem os artefatos de ASR de baixa confiança registrados na fonte de [[ibra-ai]])
- **awesome-mcp-servers** — primeira vez que um *catálogo* de servidores MCP (em vez de um MCP individual) aparece no wiki, complementando [[smithery]] como referência de descoberta de MCPs/skills

**Duas novidades estruturais**:
- **awesome** como meta-padrão: primeira "lista de listas" documentada no wiki — um nível de abstração acima dos repositórios individuais catalogados até aqui
- **public-apis** e **free-for-dev** como infraestrutura de dados/serviços gratuitos: preenchem uma lacuna do wiki — até aqui os repos substituíam ferramentas específicas (CRM, TTS, scraping), estes dois são *catálogos de acesso* a centenas de recursos gratuitos de uma vez

**langflow** é a primeira ferramenta *low-code/visual* de construção de agentes documentada no wiki — distinta das skills e frameworks baseados em prompt/código já catalogados em [[agentes-ia]]; publicável diretamente como servidor MCP, conectando-a ao ecossistema já documentado em [[awesome-mcp-servers]] e [[claude-skills]].

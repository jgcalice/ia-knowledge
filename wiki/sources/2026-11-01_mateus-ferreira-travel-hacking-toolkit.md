# Claude e o Travel Hacking Toolkit: Viaje com Menos Milhas

> **Fonte:** [[2026-11-01_mateus_ferreira_ia_para_negocios_DfNu8hoCvDX]] | **Autor:** @Mateus Ferreira | IA para negócios | **Data:** 2026-11-01 | **Formato:** reel (49s) | **[↗ Ver post](https://www.instagram.com/reel/DfNu8hoCvDX/?cplk=MXVtMnR0YXVkMW5mcA==)**

## TL;DR
O Travel Hacking Toolkit é um plugin gratuito de Claude Code (mais de 40 skills de viagem) que pesquisa 27 programas de milhas de uma vez, compara com o preço em dinheiro e indica para qual companhia vale transferir os pontos do cartão.

## Contexto
Reel de divulgação de um repositório open source criado por Borski (`github.com/borski/travel-hacking-toolkit`). O autor usa o gatilho "comenta MILHAS" para enviar o link por direct (captura de leads). A transcrição automática grafou o criador como "Bosskey"; a caption confirma "Borski".

## O que foi ensinado
- Prompt de exemplo: "acha a passagem de classe executiva mais barata pra Tóquio em dezembro".
- O plugin consulta 27 programas de milhas simultaneamente e mostra o que dá para emitir com os pontos do usuário.
- Puxa as mesmas passagens em dinheiro e calcula qual opção compensa mais.
- Para pontos de cartão, calcula para qual companhia vale transferir.
- Confere bônus de transferência (20 a 50% a mais de milhas).
- Regra de timing: só transferir os pontos depois de o assento aparecer disponível (a transferência é irreversível).

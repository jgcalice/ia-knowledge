# Aplicativo de Academia Gratuito e com IA no GitHub

> **Fonte:** [[2026-11-05_igor_henrique_DfW-8znhDvD]] | **Autor:** @Igor Henrique | **Data:** 2026-11-05 | **Formato:** reel (49s) | **[↗ Ver post](https://www.instagram.com/reel/DfW-8znhDvD/?cplk=MWRqemVkbTk3ZjBtdw==)**

## TL;DR
Um app de treino de código aberto no GitHub (~18 mil estrelas) oferece treino do dia, cronômetro de descanso, recordes, 5 mil+ exercícios animados e um treinador com IA, com hospedagem própria e licença que, segundo o autor, permite uso comercial.

## Contexto
Reel de curadoria de ferramentas, com isca de engajamento ("comenta ACADEMIA" para receber o link). O post não nomeia o projeto nem traz o link; o nome do repositório não consta na fonte. O autor divulga "prompts, skills e ferramentas de IA" diariamente.

## O que foi ensinado
- App gratuito, sem assinatura, anúncios ou cadastro obrigatório.
- Funcionalidades: treino do dia com cargas anteriores, cronômetro de descanso, recordes pessoais, evolução de cargas, mapa muscular, uso no celular.
- Biblioteca com mais de 5 mil exercícios animados.
- "Treinador com IA" para auxiliar no planejamento (detalhes do modelo/implementação não informados).
- Hospedagem própria para sincronizar entre dispositivos.
- Código aberto: dá para estudar, personalizar e criar um negócio, "respeitando os termos da licença comercial".

## Insights para o wiki
